- [ ] Navigate to Add User and back with Cancel
- [ ] Add/OK validates every required field; no persistence
## Authentication
- [ ] Login with hard-coded valid credentials
- [ ] Continue as guest
## Events
- [ ] Navigate to/from All Events
- [ ] Navigate to/from Attending events (member)

## Add Event
- [ ] Open and cancel Add Event

## RSVP
- [ ] Open and cancel RSVP page
- [ ] Member RSVP fields prefilled from hard-coded profile
- [ ] Guest RSVP fields blank
- [ ] Attempt Save validates every required field; no persistence
## Session
- [ ] Logout and return to login

## Manual test cases
For each form, test all empty, one missing field, and all filled. Test guest vs member navigation, back/cancel behavior, and login failure. Capture screenshots only after functionality works.
