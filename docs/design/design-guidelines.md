# Design Guidelines — Draft
- Low-to-mid fidelity first: clear hierarchy and navigation before visual polish.
- Home: balance **Happening This Weekend / Discover** and **Your Circle's Plans**.
- Proposed future bottom navigation: Home, Discover, Create, My Circle, Profile.
- Event list: date/time, name, location; event detail adds description and RSVP action.
- Use consistent primary/cancel actions, accessible labels, and inline validation.
- Confirm color palette, typography, and final branding after wireframe review.
