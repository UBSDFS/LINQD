# ADR 0001: Separate Product Repo and Mock-First Prototype
Status: Proposed

Decision: Keep LINQD in its own repository, use docs/product and docs/coursework separately, and use mock data + in-memory session for the first navigation prototype.

Reason: Preserve a credible product portfolio while meeting the course requirements quickly and safely.

Consequences: The prototype is demonstrable but cannot save or synchronize data; persistence and real authentication will be added later.
