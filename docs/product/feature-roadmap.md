# Feature Roadmap
## Phase 0 — Coursework prototype (this week)
- [ ] Register screen: validation, cancel, non-persistent submit
- [ ] Hard-coded login and guest access
- [ ] All / attending / hosting mock event lists
- [ ] Event detail view
- [ ] Add event: validation, cancel, non-persistent submit
- [ ] RSVP: member prefill, guest blank fields, validation, cancel, non-persistent submit
- [ ] Logout

## Phase 1 — Product MVP (proposed)
- [ ] Real user registration and secure authentication
- [ ] Public event discovery and event detail views
- [ ] Create/edit own events
- [ ] RSVP states (interested, going, not going) with persistence
- [ ] My attending and hosting event views
- [ ] Private circles and invite-only events (minimal first version)
- [ ] Profile basics and privacy controls
- [ ] Basic validation, empty states, and error handling

## Later releases
- [ ] External event-discovery API integrations
- [ ] Calendar integration
- [ ] Push notifications and RSVP reminders
- [ ] Map-based discovery and location filtering
- [ ] Event recommendations and advanced search
- [ ] Photos, social interactions, and circle enhancements
- [ ] Organizer tools, analytics, moderation, and reporting

Priorities may change after user research; do not confuse the class prototype with a launch-ready MVP.
